# Sunny Kart — Easy Chrome Installation

**[Download the Chrome extension (.zip)](https://github.com/X-mOtion/sunny-kart-motion-break/releases/latest/download/SunnyKart-Chrome-extension.zip)** · [中文图文教程](docs/INSTALL.zh-CN.md)

Follow these six steps. No commands to type.

### 1. Download

Click the download link above.

![Download the Chrome extension](docs/images/install/01-download.png)

### 2. Unzip

On Mac, double-click the ZIP. You will get a **SunnyKart-Chrome** folder. On Windows, right-click the ZIP and choose **Extract All**.

![ZIP and extracted SunnyKart-Chrome folder](docs/images/install/02-unzip.png)

### 3. Open the extensions page

Type **chrome://extensions** in Chrome’s address bar. Turn on **Developer mode** in the top-right corner.

![Extensions page and Developer mode switch](docs/images/install/03-developer-mode.png)

### 4. Load the folder

Click **Load unpacked**, select **SunnyKart-Chrome**, then click **Select**. Choose the folder, not the ZIP.

![Load unpacked and select the SunnyKart-Chrome folder](docs/images/install/04-load-folder.png)

### 5. Pin the game

Click Chrome’s **puzzle icon**, then the **pin** next to **Sunny Kart - Motion Break**.

![Pin Sunny Kart in the extensions menu](docs/images/install/05-pin.png)

### 6. Open Sunny Kart

Click the **Sunny Kart** icon in the toolbar. The game opens in a new tab.

![Sunny Kart successfully installed and opened](docs/images/install/06-ready.png)

**Done!** Click **Let us cruise** and allow your camera to play in Motion mode.

Keep the extracted folder after installation. These screenshots show Chrome on a Mac; button text follows your browser’s language.
