## Install in Chrome

1. Download **SunnyKart-Chrome-extension.zip** using the link above.
2. Extract the ZIP and locate the **SunnyKart-Chrome** folder. It should contain **manifest.json** directly inside it.
3. Open Chrome, enter **chrome://extensions** in the address bar, and turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the **SunnyKart-Chrome** folder. Select the extracted folder, not the ZIP or its parent folder.
5. Click Chrome’s **Extensions** puzzle icon and pin **Sunny Kart - Motion Break** to the toolbar.
6. Click the **Sunny Kart** icon to open the game.

Keep the extracted folder in the same location after installation. Chrome loads the extension from that folder.
