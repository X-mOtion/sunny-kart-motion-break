# Sunny Kart — 手动安装（备用方式）

**[下载 Chrome 插件（ZIP）](https://github.com/X-mOtion/sunny-kart-motion-break/releases/latest/download/SunnyKart-Chrome-extension.zip)** · [English guide](INSTALL.manual.en.md)

照着下面的图片点击即可，不需要输入任何命令。

### 1. 下载插件

点击上方下载链接。

![下载插件](images/install/01-download.png)

### 2. 解压 ZIP

Mac 双击 ZIP；Windows 右键选择“全部解压”。解压后会得到 **SunnyKart-Chrome** 文件夹。

![ZIP 和解压后的插件文件夹](images/install/02-unzip.png)

### 3. 打开扩展页面

在 Chrome 地址栏输入 **chrome://extensions**，打开右上角的 **开发者模式**。

![地址栏和开发者模式开关](images/install/03-developer-mode.png)

### 4. 加载插件文件夹

点击 **加载未打包的扩展程序**（部分版本叫“加载已解压的扩展程序”），选择 **SunnyKart-Chrome** 文件夹，再点击 **选择**。请选择文件夹，不要选择 ZIP。

![加载插件并选择正确的文件夹](images/install/04-load-folder.png)

### 5. 固定到工具栏

点击 Chrome 工具栏的 **拼图图标**，再点击 **Sunny Kart - Motion Break** 旁边的 **图钉**。

![固定 Sunny Kart](images/install/05-pin.png)

### 6. 打开游戏

点击工具栏的 **Sunny Kart** 图标，游戏就会打开。

![插件安装成功并正常打开游戏](images/install/06-ready.png)

**安装完成！** 点击 **Let us cruise**，允许摄像头，即可使用 Motion 模式。

安装后请保留解压文件夹。截图来自 Mac 上的实际安装过程。
