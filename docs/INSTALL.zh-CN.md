# Sunny Kart — 商店安装，三步开始玩

**[从 Chrome 应用商店安装](https://chromewebstore.google.com/detail/sunny-kart-motion-break/fmghnfigogeolhhmpbnpceiiaichepoa)** · [English guide](../README.md)

在电脑上使用 Google Chrome，跟着下面三步即可。

### 1. 安装插件

用 **Google Chrome** 打开上方商店链接。点击 **添加至 Chrome**，再在 Chrome 的确认窗口中点击 **添加扩展程序**。

### 2. 固定到工具栏

点击 Chrome 工具栏的 **拼图图标**，再点击 **Sunny Kart - Motion Break** 旁边的 **图钉**。

![固定 Sunny Kart](images/install/05-pin.png)

### 3. 打开并开始玩

点击工具栏的 **Sunny Kart** 图标。游戏打开后默认选择 **Motion**，点击 **Let us cruise**，允许摄像头即可开始。

![游戏已打开，可以开始玩](images/install/06-ready.png)

让头部和双肩保持在画面里：**歪头变道、倾肩转弯、耸肩加速**。也可以选择 **Keyboard**，不用摄像头即可玩。

通过商店安装后，Chrome 会自动更新插件。截图来自 Mac，按钮名称会随浏览器语言变化。

想使用 ZIP 安装包？查看[手动安装图文教程](INSTALL.manual.zh-CN.md)。
