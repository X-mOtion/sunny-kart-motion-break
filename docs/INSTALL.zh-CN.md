# Sunny Kart — Chrome 插件安装

**[下载 Chrome 插件（ZIP）](https://github.com/X-mOtion/sunny-kart-motion-break/releases/latest/download/SunnyKart-Chrome-extension.zip)**

[English installation guide](../README.md)

## 安装步骤

1. 点击上方链接，下载 **SunnyKart-Chrome-extension.zip**。
2. 解压 ZIP，找到 **SunnyKart-Chrome** 文件夹。打开这个文件夹，应直接看到 **manifest.json**。
3. 打开 Chrome，在地址栏输入 **chrome://extensions**，开启右上角的 **开发者模式 / Developer mode**。
4. 点击 **加载已解压的扩展程序 / Load unpacked**，选择 **SunnyKart-Chrome** 文件夹。请选择解压后的文件夹，不要选择 ZIP 或外层目录。
5. 点击 Chrome 工具栏的拼图图标，固定 **Sunny Kart - Motion Break**。
6. 点击 **Sunny Kart** 图标，即可打开游戏。

安装后请保留解压文件夹，不要移动或删除。Chrome 会从该文件夹加载插件。
